# Street Striker (Phaser 2D 格闘ゲーム)

Phaser 3 + TypeScript で構築された本格2D格闘ゲームです。
ストリートファイター6のドライブシステム（ドライブインパクト、ドライブパリィ、オーバードライブ、パニッシュカウンター、バーンアウト）と6ボタン操作システムを搭載しています。

## 特徴

- **全6体のプレイアブルキャラクター**:
  1. **TOMOE (SAMURAI)**: 居合抜刀剣士（近接特化・一閃）
  2. **TITUS (GLADIATOR)**: 重装グラディエーター（アーマー・パワースラッガー）
  3. **KENJI (NINJA)**: 忍術双剣士（高速ダッシュ・二刀手数のラッシュ）
  4. **AYANE (VALKYRIE)**: 戦乙女・武闘家（空中機動・サマーソルトキック）
  5. **KAIZER (CYBORG)**: サイボーグ重装兵（バーニア噴射・プラズマハンマー）
  6. **KURENAI (KUNOICHI)**: 紫影のくのいち（飛び道具・遠距離苦無投擲）
- **飛び道具システム**: 独立した苦無（クナイ）実弾エンティティ、忍気粒子トレイル、喰らい判定交差、ガード削り。
- **キャラクター選択画面 (SelectScene)**: 起動時のキャラ選択、1P/2Pプレビュー、CPU/対人切替、ステージ切替。
- **2つの対戦ステージ**:
  - サイバー道場 (`CYBER DOJO`)
  - クラシック道場 (`CLASSIC DOJO`)
- **本格SF6ドライブシステム**:
  - ドライブインパクト（アーマー耐え＋確定パニッシュ崩れ演出）
  - ドライブパリィ / ジャストパリィ
  - ドライブゲージ / バーンアウト状態
  - スーパーアーツ (SA) ゲージ & 必殺技演出
- **アケコン (USB アーケードコントローラー) & キーボード完全対応**

## 操作方法

### キャラクター選択画面
- `[A] / [D]`: 1P キャラクター選択
- `[←] / [→]`: 2P キャラクター選択
- マウスクリック: 左クリックで 1P 選択、Shift+クリックで 2P 選択
- `[C]`: 2P CPU戦（BOT）/ 対人戦（MANUAL）切替
- `[T]`: ステージ切替
- `[SPACE] / [ENTER]`: 対戦開始！

### バトル操作 (1P キーボード)
- `[W]`: ジャンプ
- `[A] / [D]`: 後退（ガード） / 前進
- `[S]`: しゃがみ構え / `[S + D]`: しゃがみ歩き / `[S + A]`: しゃがみガード
- `[U] / [I] / [O]`: 弱パンチ / 中パンチ / 強パンチ
- `[J] / [K] / [L]`: 弱キック / 中キック / 強キック
- `[P]`: ドライブインパクト
- `[SPACE]`: ドライブパリィ
- `[M]`: スーパーアーツ (SA)
- `[ESC]`: キャラクター選択画面へ戻る
- `[R]`: ラウンド再戦

## 開発環境 & 起動方法

```bash
# 依存パッケージのインストール
npm install

# 開発サーバー起動
npm run dev

# プロダクションビルド
npm run build
```
